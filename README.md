# FileDial — прототип

Выделите видеофайл в Проводнике или на рабочем столе и нажмите **Ctrl+Alt+K**: у курсора появится
круговое меню с действиями для этого файла. В прототипе работает одно действие — «Сжать до 25 МБ».
Всё работает офлайн.

## Требования

- Windows 10/11 x64.
- .NET 10 SDK (для сборки) или .NET 10 Desktop Runtime (для запуска собранного exe).
- `ffmpeg.exe` и `ffprobe.exe` — см. «Установка ffmpeg».

## Сборка и запуск

```powershell
dotnet build
dotnet test
dotnet run --project src/FileDial.App
```

Собранная программа: `src/FileDial.App/bin/Debug/net10.0-windows/FileDial.exe`.
Права администратора не нужны и не запрашиваются (`asInvoker`). Окон нет, только значок в трее;
выход — правой кнопкой по значку → «Выход». Второй экземпляр не запускается.

Если **Ctrl+Alt+K** уже занято другой программой, FileDial покажет сообщение и завершится.

## Установка ffmpeg

FileDial ищет **оба** файла `ffmpeg.exe` и `ffprobe.exe` в одной папке, сначала рядом с `FileDial.exe`,
затем в папках из переменной `PATH`. Способы:

1. **Рядом с программой (проще всего).** Скачайте сборку ffmpeg для Windows (например, «release essentials»
   с gyan.dev или сборку BtbN на GitHub), распакуйте и скопируйте `bin\ffmpeg.exe` и `bin\ffprobe.exe`
   в папку с `FileDial.exe`.
2. **Через winget:** `winget install Gyan.FFmpeg`, затем перезапустите FileDial, чтобы он увидел новый `PATH`.
3. **Вручную в PATH:** добавьте папку `bin` распакованного ffmpeg в переменную среды `PATH` пользователя
   и перезапустите FileDial.

Если ffmpeg не найден, окно сжатия покажет сообщение со ссылкой на этот раздел.

## Как пользоваться

1. Выделите один файл `.mp4`, `.mov`, `.mkv` или `.webm` в Проводнике или на рабочем столе.
2. Нажмите **Ctrl+Alt+K** — круг откроется у курсора.
3. Выберите сектор мышью или клавишами **1–8** (1 — верхний сектор, дальше по часовой стрелке).
   Клик или **Enter** запускает действие.
4. **Esc**, клик в центре/вне круга, правый клик или переключение на другое окно закрывают круг
   без каких-либо изменений.

Для других типов файлов, папок и нескольких выделенных файлов показывается небольшой круг без секторов
с надписью «Пока не поддерживается». Длинные имена сокращаются в середине, расширение остаётся видно.
Для видео в центре показаны размер и длительность (если ffmpeg найден).
Если активное окно — не Проводник, ничего не выделено или файл недоступен, у курсора появляется
короткое уведомление.

### Сжатие до 25 МБ

- Цель — 25 000 000 байт. Длительность берётся из `ffprobe`.
- Двухпроходное кодирование H.264 (`libx264`, preset medium) + AAC 128 кбит/с.
  Общий битрейт = 25 000 000 × 8 × 0,97 / длительность (запас 3%), видео = общий − 128.
- Если на видео остаётся меньше 300 кбит/с, длинная сторона кадра уменьшается до 854 / 640 / 426 пикселей
  (в зависимости от битрейта).
- Сектор «Сжать до 25 МБ» не предлагается, если сжатие не нужно или невозможно. Причина видна в центре круга:
  - файл уже не больше 25 МБ — «Файл уже меньше 25 МБ»;
  - на изображение осталось бы меньше 50 кбит/с — «Видео длиннее 18 мин в 25 МБ не уместить»
    (без звука предел около 64 минут);
  - в файле нет видеодорожки.

  Длительность проверяется через ffprobe при открытии круга (~50 мс, таймаут 2 с). Если ffmpeg не найден
  или ffprobe не ответил, сектор остаётся активным, а окно сжатия объяснит проблему.
- Если после второго прохода файл всё же вышел больше цели, второй проход один раз повторяется
  с битрейтом, уменьшенным на величину перебора («Проход 2 из 2, уточнение»).
- Результат: `имя_25мб.mp4` рядом с исходником; если имя занято — `имя_25мб_2.mp4`, `имя_25мб_3.mp4`…
  Существующие файлы не перезаписываются. Исходный файл только читается.
- Временные файлы (`.filedial-*.tmp` рядом с исходником и журналы проходов в `%TEMP%\FileDial`)
  удаляются и при успехе, и при ошибке, и при отмене.
- Окно прогресса показывает этап и проценты (из `ffmpeg -progress`), есть кнопка «Отмена».
  По завершении — итоговый размер и кнопка «Показать в папке».

## Ограничения

- **Окна с правами администратора.** FileDial работает без прав администратора. Если окно Проводника
  запущено с повышенными правами, Windows (UIPI и уровни целостности) не даёт обычному процессу читать
  из него выделение. FileDial распознаёт такую ситуацию и показывает уведомление «Окно запущено с правами
  администратора — выделение недоступно». Запускать FileDial от администратора ради этого не нужно и не
  рекомендуется.
- Фокус: круг забирает фокус клавиатуры сразу после открытия (Windows разрешает это процессу, получившему
  горячую клавишу). Если система всё же не отдала фокус, круг закрывается через ~0,4 с, чтобы не
  остаться висеть поверх окон.
- Выделение читается только из обычных окон Проводника (`CabinetWClass`) и рабочего стола.
  Диалоги «Открыть/Сохранить» других программ не поддерживаются.
- Виртуальные элементы (например, внутри zip-архива, «Этот компьютер», корзина) считаются недоступными.
- Непредвиденные ошибки пишутся в `%LOCALAPPDATA%\FileDial\errors.log` и не роняют программу.

## Как устроено

```
src/FileDial.Core         логика без UI и WinAPI (тестируется)
  Menu/                   действия по типу файла, разбор выделения → круг или уведомление
  Geometry/               геометрия секторов, размещение окна в пределах монитора
  Compression/            расчёт битрейта, имя результата, аргументы и запуск ffmpeg/ffprobe, прогресс
  Selection/              результат чтения выделения, проверка файла
src/FileDial.App          WPF-приложение
  Hotkey/                 RegisterHotKey в окне сообщений (без глобальных хуков)
  Selection/              чтение выделения через COM оболочки в отдельном STA-потоке
  UI/                     круг, уведомление, окно сжатия, размещение с учётом DPI
  Tray/                   значок в трее
tests/FileDial.Core.Tests xUnit-тесты
```

Получение выделения (без эмуляции Ctrl+C и без буфера обмена):

- `GetForegroundWindow` → класс окна.
- **Проводник** (`CabinetWClass`): `Shell.Application.Windows()`, отбор по `HWND`. В Windows 11 у всех
  вкладок одного окна общий `HWND`, поэтому для каждого кандидата через
  `IServiceProvider::QueryService(SID_STopLevelBrowser) → IShellBrowser::GetWindow` берётся окно вкладки
  и сравнивается с видимым дочерним `ShellTabWindowClass` — это активная вкладка. Если активную вкладку
  определить не удалось, выделение не читается (ошибка, а не данные из чужой вкладки).
  Затем `Document.SelectedItems()`.
- **Рабочий стол** (`Progman` или `WorkerW` с `SHELLDLL_DefView`): `IShellWindows::FindWindowSW(SWC_DESKTOP)` →
  `IShellBrowser::QueryActiveShellView` → `IShellView::GetItemObject(SVGIO_BACKGROUND)` → `SelectedItems()`.
- Все COM-вызовы — в отдельном STA-потоке с таймаутом 5 с; COM-объекты освобождаются, исключения
  перехватываются.
- ffmpeg/ffprobe запускаются через `ProcessStartInfo.ArgumentList` — каждый аргумент отдельно, поэтому
  пути с пробелами и кириллицей передаются без ручного экранирования.

## Тесты

`dotnet test` запускает:

- юнит-тесты: расчёт битрейта и уменьшения разрешения, геометрия секторов и попадание мышью, клавиши 1–8,
  размещение окна у краёв и на мониторе с отрицательными координатами, масштаб DPI, выбор действий по типу
  файла, разбор выделения (один файл / несколько / папка / ничего / недоступен), генерация имени результата,
  поиск ffmpeg, разбор `-progress` и ответа ffprobe, аргументы ffmpeg;
- интеграционные тесты с настоящим ffmpeg (пропускаются, если ffmpeg не найден): сжатие в папке
  с кириллицей и пробелами, размер не больше цели, исходник не изменён, временные файлы удалены,
  отсутствие перезаписи (`_2`), уменьшение разрешения, «уже меньше цели», отмена.

## Ручной сценарий проверки

Подготовьте видео больше 25 МБ (например, 1–3 минуты 1080p). Запустите `FileDial.exe` **без** прав
администратора, убедитесь, что появился значок в трее и нет других окон.

| # | Сценарий | Действия | Ожидаемый результат |
|---|----------|----------|---------------------|
| 1 | Файл на рабочем столе | Положите видео на рабочий стол, выделите, Ctrl+Alt+K | Круг у курсора, в центре имя и размер; 8 секторов, активен только «Сжать до 25 МБ» |
| 2 | Сжатие | В круге — клик по «Сжать до 25 МБ» (или 1, Enter) | Окно прогресса, проценты растут, UI отзывчив; в конце размер ≤ 25 МБ и «Показать в папке» открывает папку с выделенным `имя_25мб.mp4` |
| 3 | Две вкладки Проводника | Окно с двумя вкладками в разных папках, в каждой выделено своё видео; переключайтесь между вкладками и жмите Ctrl+Alt+K | Каждый раз в круге файл **активной** вкладки, никогда — из соседней |
| 4 | Кириллица и пробелы | Видео в `D:\Мои видео\Отпуск в горах\клип 1.mp4`, сжать | Сжатие проходит, рядом появляется `клип 1_25мб.mp4` |
| 5 | Повторное сжатие | Сжать тот же файл ещё раз | Появляется `…_25мб_2.mp4`, первый результат не тронут |
| 6 | Несколько файлов | Выделите 2+ файла, Ctrl+Alt+K | Небольшой круг без секторов: «Выделено объектов: N», «Пока не поддерживается» |
| 7 | Другой тип | Выделите `.jpg` или `.pdf` | Небольшой круг без секторов с именем, размером и «Пока не поддерживается» |
| 8 | Ничего не выделено | Снимите выделение в Проводнике, Ctrl+Alt+K | Уведомление «Ничего не выделено» у курсора |
| 9 | Не Проводник | Активен Блокнот/браузер, Ctrl+Alt+K | Уведомление «Активное окно — не Проводник» |
| 10 | Esc и клики | Откройте круг: Esc; ещё раз — клик в центре; ещё раз — клик мимо круга; ещё раз — Alt+Tab | Круг закрывается, файлы не меняются |
| 11 | Неактивный сектор | Наведите на «Обрезать» или нажмите 2, затем Enter/клик | Подсказка «Недоступно в прототипе», ничего не запускается |
| 12 | Отмена сжатия | Начните сжатие, нажмите «Отмена» (или закройте окно) | «Сжатие отменено»; рядом с исходником нет `.filedial-*.tmp` и `_25мб.mp4`, в `%TEMP%\FileDial` пусто |
| 13 | Файл меньше 25 МБ | Выделите видео < 25 МБ, Ctrl+Alt+K | Сектор «Сжать до 25 МБ» неактивный, в центре «Файл уже меньше 25 МБ»; клик/Enter ничего не делают |
| 13а | Длинное видео | Выделите видео длиннее 18 минут (больше 25 МБ), Ctrl+Alt+K | В центре размер и длительность; «Сжать до 25 МБ» неактивен с причиной «Видео длиннее 18 мин…» |
| 13б | Длинное имя | Видео с именем из 50+ символов | В центре имя с «…» посередине, расширение видно |
| 14 | Нет ffmpeg | Временно уберите ffmpeg из PATH и из папки программы, перезапустите FileDial, запустите сжатие | Сообщение «Не найдены ffmpeg.exe и ffprobe.exe…» и ссылка, открывающая этот README |
| 15 | Второй монитор | Перенесите Проводник на второй монитор (желательно с другим масштабом, например 100% и 150%), откройте круг у самого края | Круг на том же мониторе, что и курсор, не выходит за край, правильного размера и чёткий |
| 16 | Край экрана | Откройте круг у угла экрана и у панели задач | Круг целиком в рабочей области |
| 17 | Занятая клавиша | Закройте FileDial, займите Ctrl+Alt+K скриптом ниже, запустите FileDial | Сообщение «Сочетание Ctrl+Alt+K уже занято другой программой»; FileDial не остаётся в трее без клавиши. Повторный запуск при работающем FileDial сообщает «FileDial уже запущен» |
| 18 | Окно администратора | Запустите Проводник с правами администратора (например, из диспетчера задач с флажком «Создать задачу с правами администратора»: `explorer.exe /separate`), выделите файл, Ctrl+Alt+K | Уведомление про права администратора, без падения |
| 19 | Выход | Трей → «Выход» во время сжатия | ffmpeg завершается, временные файлы удалены, процесс FileDial закрыт |

Скрипт для сценария 17 (держит Ctrl+Alt+K, пока открыто окно PowerShell; Enter — освободить):

```powershell
Add-Type -Name Hk -Namespace W -MemberDefinition '[DllImport("user32.dll")] public static extern bool RegisterHotKey(IntPtr h, int id, uint m, uint vk); [DllImport("user32.dll")] public static extern bool UnregisterHotKey(IntPtr h, int id);'
[W.Hk]::RegisterHotKey([IntPtr]::Zero, 1, 3, 0x4B); Read-Host 'Ctrl+Alt+K занято, Enter — освободить'; [W.Hk]::UnregisterHotKey([IntPtr]::Zero, 1)
```
