# FileDial — прототип

Выделите видео, картинку, аудиофайл, архив, PDF, документ, текстовый файл, SVG или значок в Проводнике или на рабочем
столе и нажмите **Ctrl+Alt+K** (или правый клик → «Открыть в FileDial…»): у курсора появится круговое меню с действиями
для этого типа файла. Всё работает офлайн.

| Тип | Расширения | Секторы (неактивные — курсивом) |
|-----|------------|---------------------------------|
| Видео | mp4, mov, mkv, webm | Сжать до 25 МБ, Обрезать, Сделать GIF, Извлечь звук, Кадр в картинку, Субтитры, Убрать звук, **Формат ›** MP4 · MKV · WebM · MOV |
| Изображения | jpg, jpeg, png, webp, bmp, gif, tif, tiff | **Формат ›** JPG · PNG · WebP · BMP · TIFF · GIF · ICO, Уменьшить до 1920 px, Повернуть вправо, Повернуть влево, Отразить, Сжать до 1 МБ, Убрать фон, В PDF |
| Звук | mp3, wav, flac, m4a, aac, ogg, opus, wma | **Формат ›** MP3 · M4A · WAV · FLAC · OGG · Opus, Выровнять громкость, Убрать шум, Ускорить ×1,5, Замедлить ×0,75, В моно, Обрезать, В текст |
| Архивы | zip, 7z, rar, tar, tar.gz/tgz, tar.bz2, tar.xz | Распаковать сюда, Распаковать в папку, Распаковать в…, Проверить архив, **Формат ›** ZIP · 7z, Защитить паролем, Разбить на части, Содержимое |
| PDF | pdf | Разделить по страницам, Извлечь страницы, Повернуть вправо, Повернуть влево, Страницы в картинки, Распознать текст, Защитить паролем, *Объединить* (для нескольких PDF) |
| Документы | docx, doc, rtf, odt · xlsx, xls, ods · pptx, ppt, odp | В PDF, **Формат ›** (тексты: DOCX · ODT · RTF; таблицы: XLSX · ODS · CSV; презентации: PPTX · ODP), В текст, Извлечь картинки, Сжать картинки, Убрать личные данные, Защитить паролем, *Собрать в PDF* (для нескольких документов) |
| Текст | txt, text, csv, tsv, json, xml, md, markdown, log, ini, cfg, conf, yaml, yml | В UTF-8, **Переводы строк ›** CRLF · LF, В XLSX (CSV/TSV), Форматировать JSON, Сжать JSON, В HTML (Markdown), В PDF (Markdown) |
| SVG | svg | В PNG, PNG всех размеров, В ICO |
| Значки | ico | В PNG, Все размеры в PNG |
| Части файла | имя.zip.001, .002, … | компактный круг: **Enter или клик — собрать из частей** |
| Всё остальное | psd, exe, папки, файлы разных типов… | компактный круг: **Enter или клик — сжать в ZIP** |

**Формат ›**, **Переводы строк ›** и **Ещё ›** (см. «Мои действия») — секторы-группы (отмечены треугольником
у внешнего края): при наведении снаружи круга раскрывается веер. Свой же формат в веере неактивен («Файл уже в PNG»).
«Объединить» и «Собрать в PDF» неактивны для одного файла («Выделите несколько PDF»). Остальные секторы неактивны,
только когда действие для этого конкретного файла бессмысленно или невозможно, и подсказка объясняет почему.
«Субтитры» и «В текст» работают, если есть модель распознавания речи (см. «Распознавание речи»), «Убрать фон» — если
скачана его модель (см. «Убрать фон»); без модели эти секторы предлагают её скачать.

### Несколько файлов

Выделите несколько файлов **одного типа** (например, 5 картинок) — круг покажет «5 картинок» и общий размер,
а выбранное действие выполнится для каждого файла по очереди. Окно показывает общий прогресс
(«2 из 5 · снимок.png · Обработка»), в конце — итог: «Готово: 4 из 5. Пропущено: 1…»; ошибка одного файла
не останавливает остальные, «Отмена» останавливает всё. В историю попадает каждый файл отдельно.

- Файлы, уже находящиеся в целевом формате, пропускаются (а не копируются). Формат в веере неактивен,
  только если в нём уже **все** файлы.
- «Сжать до…» неактивно, только если меньше цели **все** файлы; маленькие пропускаются.
- «Обрезать», «Содержимое» и «Извлечь страницы» — только для одного файла.
- Картинки: «Собрать в PDF» — один документ, по картинке на страницу в порядке выделения.
- Текстовые файлы (например, .txt, .csv и .json вместе считаются одним типом): действие активно, если оно нужно хотя
  бы одному файлу; файлы, к которым оно не относится, пропускаются («Только для файлов JSON», «Уже в кодировке UTF-8»).
- Файлы разных типов или выделение с папками — компактный круг с причиной в центре («Файлы разных типов», «Среди
  выделенного есть папки») и **Enter или клик — сжать в ZIP**.
- Больше 200 объектов — «Не больше 200 за раз» и «Пока не поддерживается».

### PDF из картинок

«В PDF» (одна картинка) и «Собрать в PDF» (несколько) пишут PDF сами, без сторонних библиотек: каждая картинка
приводится к JPEG (прозрачность — на белом), страница — размер картинки при 96 dpi. Имя: для одной картинки —
`имя.pdf`, для нескольких — по имени папки (`Отпуск.pdf`).

## Требования

- Windows 10/11 x64.
- .NET 10 SDK — только для сборки из исходников; собранному `FileDial.exe` из `publish.ps1` .NET не нужен.
- ffmpeg — программа ставит его сама одной кнопкой (см. «Установка ffmpeg»). Не нужен для архивов, PDF, документов
  (кроме «Сжать картинки» в документе), текстовых файлов и значков. Нужен для SVG, картинки → ICO и «Убрать фон»
  (ffmpeg читает и пишет картинки).
- SVG требует ffmpeg с декодером librsvg. Сборка gyan.dev «full», которую ставит FileDial, содержит его не всегда
  (проверенная здесь «full» 9.0.1 — нет), см. «Ограничения».
- Для документов «В PDF», «Формат», «Собрать в PDF» и текста из DOC/RTF/PPT — **Microsoft Office** или
  **LibreOffice** (что-то одно; если есть оба — используется Office). Без них эти секторы неактивны
  с причиной, остальное работает. «Защитить паролем» у документа — только через Office.
- «Распознать текст» в PDF — встроенное в Windows распознавание: нужен язык с компонентом «Распознавание
  текста» (обычно ставится вместе с языком интерфейса).
- Markdown → PDF печатается через **Microsoft Edge** (есть в Windows 10/11); без Edge сектор неактивен.
- «Убрать фон» запускает нейросеть на процессоре, видеокарта не нужна. Модель (179 МБ) скачивается один раз
  из настроек.

## Сборка и запуск

```powershell
dotnet build
dotnet test
dotnet run --project src/FileDial.App
```

Собранная программа: `src/FileDial.App/bin/Debug/net10.0-windows10.0.19041.0/FileDial.exe`.
Права администратора не нужны и не запрашиваются (`asInvoker`). Окон нет, только значок в трее. В меню значка —
«Настройки…», «История…», «Справка (README)», «Проверить обновления» (только в сборках с проверкой обновлений,
см. «Обновления») и «Выход». Второй экземпляр не запускается (`--dial` из контекстного меню лишь просит запущенную
копию открыть круг).

Если горячая клавиша уже занята другой программой, FileDial сообщит об этом и сразу откроет настройки,
чтобы выбрать другое сочетание (без клавиши программа остаётся в трее и не выходит).

## Настройки

Трей → «Настройки…» или двойной клик по значку. Изменения применяются по «Сохранить»; если применить
не удалось (например, сочетание занято), окно остаётся открытым с причиной.

| Настройка | По умолчанию | Что делает |
|-----------|--------------|------------|
| Язык | Как в Windows | Язык интерфейса: «Как в Windows», Русский или English (см. «Языки»). Выбранный язык виден сразу; без «Сохранить» возвращается прежний |
| Горячая клавиша | Ctrl+Alt+K | Щёлкните поле и нажмите сочетание. Нужен Ctrl, Alt или Win и буква, цифра или F1–F24. Новое сочетание регистрируется сразу; если оно занято, остаётся прежнее |
| Запускать вместе с Windows | выкл. | Запись в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` — без прав администратора, только для текущего пользователя |
| Пункт «Открыть в FileDial…» в меню Проводника | вкл. | Пункт контекстного меню для файлов и папок (см. «Контекстное меню Проводника») |
| Оформление | Графит | Тема круга и окон: «Графит» (тёмная, салатовый акцент), «Латунь» (тёмная тёплая, латунный акцент), «Бумага» (светлая, синий акцент), «Как в Windows» — Графит или Бумага по теме приложений Windows. Выбранная тема видна сразу; без «Сохранить» возвращается прежняя |
| Анимации | вкл. | Выключает все анимации FileDial (выключенные анимации Windows тоже учитываются) |
| Вести историю действий | вкл. | Записывает каждое действие в историю (см. ниже). Выключение не удаляет уже записанное |
| Проверять обновления раз в неделю | вкл. | Видна только в сборках с проверкой обновлений (см. «Обновления») |
| Куда сохранять результаты | рядом с исходным файлом | Либо в выбранную папку. Временные файлы тоже создаются там, исходная папка остаётся чистой |
| Открывать папку с результатом после завершения | выкл. | Сразу показывает результат в Проводнике |
| Сжатие видео — цель | 25 МБ | 8 / 10 / 25 / 50 / 100 МБ. Меняет подпись сектора, проверку «уже меньше» и имя (`имя_10мб.mp4`) |
| Сжатие картинок — цель | 1 МБ | 500 КБ / 1 / 2 / 5 МБ, аналогично |
| ffmpeg | авто | Папка с `ffmpeg.exe` и `ffprobe.exe`; проверяется первой. Под полем видно, какой ffmpeg будет использован |
| Распознавание речи | — | Загрузка и выбор модели, язык распознавания (см. «Распознавание речи») |
| Мои действия | пусто | Свои команды в круге (см. «Мои действия») |
| Удаление фона | — | Загрузка модели для «Убрать фон» (см. «Убрать фон») |

## Языки

Интерфейс доступен на русском и английском. По умолчанию язык берётся из языка интерфейса Windows: русский —
для русско-, белорусско- и казахскоязычной Windows, английский — для остальных. Сменить его можно в Настройки →
«Язык» или в установщике. Имена файлов-результатов тоже следуют языку интерфейса (`имя_25мб.mp4` по-русски,
`name_25mb.mp4` по-английски).

Все строки лежат в `src/FileDial.Core/Localization`: абстрактный класс `Texts` и по наследнику на язык
(`RuTexts`, `EnTexts`). Новый язык — ещё один наследник `Texts` и его код в `Lang`; не переведённая строка —
ошибка сборки, а не пустое место в окне.

## Контекстное меню Проводника

Правый клик по файлу, нескольким файлам или папке в Проводнике или на рабочем столе → **«Открыть в FileDial…»**:
у курсора открывается круг для текущего выделения — точно так же, как по горячей клавише. Это для тех, кто
не помнит сочетание.

- В **Windows 11** пункт находится в классическом меню: «Показать дополнительные параметры» (или Shift+F10 /
  Shift+правый клик). Новое меню Windows 11 принимает пункты только от упакованных приложений, а FileDial не такое.
- Пункт записывается в `HKCU\Software\Classes\*\shell\FileDial` и `HKCU\Software\Classes\Directory\shell\FileDial`
  (только текущий пользователь, без прав администратора). Он запускает `"FileDial.exe" --dial` один раз на всё
  выделение.
- Если FileDial уже запущен, `--dial` только просит запущенную копию открыть круг и сразу выходит. Если не запущен —
  FileDial стартует (и остаётся в трее) и открывает круг.
- Пункт включён по умолчанию. Выключить его можно в Настройки → «Общее» или в установщике («Пункт в меню
  Проводника»). При каждом запуске FileDial переписывает пункт на текущий exe и язык интерфейса, поэтому переезд
  между переносной и установленной копией не оставляет сломанного пункта. Удаление убирает пункт, только если он
  указывает на удаляемую копию.

## Распознавание речи

«Субтитры» (видео → `имя.srt`) и «В текст» (звук → `имя.txt`) используют фильтр `whisper`, встроенный
в ffmpeg 8 и новее (whisper.cpp). Распознавание идёт офлайн; нужна модель — её не нужно искать и скачивать вручную:

- **Из круга.** Без модели «Субтитры» и «В текст» неактивны с подсказкой «Нужна модель распознавания речи —
  Enter: скачать». Enter или клик открывает настройки сразу на нужном разделе.
- **В настройках** → «Распознавание речи»: кнопки «Скачать: базовая (148 МБ)» и «Скачать: точная (487,6 МБ)».
  Прогресс и «Отмена» видны там же. Файл скачивается с официального репозитория whisper.cpp на Hugging Face
  во временный `.part`, проверяется по размеру и SHA-256 и только потом кладётся в
  `%LOCALAPPDATA%\FileDial\models`. Битый или недокачанный файл удаляется. Это нужно один раз.
- **В комплекте.** Положите `ggml-*.bin` в папку `models` рядом с `FileDial.exe` — модель найдётся сама,
  интернет не понадобится вообще (так собирается полностью офлайн-дистрибутив).

Выбор модели: явно указанная в настройках → из `models` рядом с программой → скачанная; точная (small)
предпочтительнее базовой. Язык — «Авто», «Русский», «English» (для коротких записей лучше указать язык).
Если ffmpeg собран без whisper — «Ваш ffmpeg собран без whisper» (сборки ffmpeg 8+ «full» от gyan.dev его содержат).
Если речи в файле нет, результат не создаётся («Речь не найдена»). Нумерация SRT начинается с 1.

## Убрать фон

«Убрать фон» в круге картинки создаёт рядом с исходником `имя_без_фона.png` — PNG с прозрачным фоном. Маску
считает нейросеть **IS-Net** (модель общего назначения, лицензия Apache-2.0) через **ONNX Runtime** на процессоре,
офлайн.

- **Модель.** Без неё сектор неактивен с подсказкой «Нужна модель для фона (179 МБ) — Enter: скачать»; Enter или
  клик открывает Настройки → «Удаление фона», где кнопка «Скачать модель (179 МБ)» скачивает
  `isnet-general-use.onnx` из выпусков проекта rembg на GitHub (прогресс и «Отмена» там же). Файл проверяется
  по размеру и SHA-256 и только после проверки кладётся в `%LOCALAPPDATA%\FileDial\models`. Для офлайн-дистрибутива
  положите его в `models\` рядом с `FileDial.exe`.
- Картинку читает и пишет ffmpeg: годится любой поддерживаемый формат, поворот по EXIF учитывается, у анимированных
  GIF/WebP берётся первый кадр, имеющаяся прозрачность сохраняется.
- Картинки больше 40 мегапикселей сначала уменьшаются («Картинка очень большая — результат уменьшен до Ш×В.»).
- Скорость: обычное фото 3840×2400 — около 4 с. Нейросеть остаётся загруженной минуту после последнего
  использования, поэтому пакет картинок загружает её один раз.
- Исходник не меняется; если имя занято — `имя_без_фона_2.png`. Работает и для нескольких картинок сразу.

## Мои действия

Настройки → «Мои действия» → «Добавить…» добавляет в круг свою команду: любую программу с шаблоном аргументов.

| Поле | Что значит |
|------|------------|
| Название | Подпись сектора (до 60 символов; длинная подпись в секторе сокращается) |
| Для каких файлов | «Любые», «Видео», «Картинки», «Звук», «PDF», «Документы», «Архивы» или «По расширению» (`txt, md, log`) |
| Программа | Полный путь к `.exe`, имя программы из `PATH` или системных папок (`notepad.exe`) либо `{ffmpeg}` — ffmpeg, который нашёл FileDial |
| Аргументы | Шаблон с переменными (см. ниже) |
| Файл результата (для `{out}`) | «Добавка к имени» и «Расширение» (пустое — как у исходного файла) |
| Показывать окно программы | Без `{out}` программа просто открывается, FileDial её не ждёт. С `{out}` — ждёт завершения |

Переменные: `{file}` — полный путь, `{dir}` — папка, `{name}` — имя без расширения, `{ext}` — расширение,
`{out}` — новый файл рядом с исходным (или в папке результатов): `имя<добавка>.<расширение>`, без перезаписи
(`имя_2…`), `{ffmpeg}` — путь к ffmpeg. Редактор показывает «Команду для примера» и примеры «ffmpeg: 720p»
(`{ffmpeg} -i {file} -vf scale=-2:720 {out}`, добавка `_720p`, расширение `mp4`), «Блокнот» (`notepad.exe {file}`
с окном) и «ImageMagick» (`magick {file} -resize 50% {out}`; нужен установленный ImageMagick).

- **Без командной оболочки.** Программа запускается напрямую, аргументы передаются списком: шаблон делится по
  пробелам, кавычки группируют слова и убираются, `""` внутри кавычек — сама кавычка, обратная косая черта не особая.
  Переменная подставляется внутрь своего аргумента, поэтому пути с пробелами, кириллицей или кавычками остаются одним
  аргументом и не могут превратиться в команду. Запускаются только `.exe` и `.com`; `.bat` и `.cmd` отклоняются
  (cmd.exe заново разобрал бы строку) — скрипт запускайте через его программу, например
  `powershell.exe -File script.ps1 {file}`.
- Рабочая папка — папка файла. Успех — код возврата 0 и, если в шаблоне есть `{out}`, появившийся файл результата.
  Иначе окно действия показывает ошибку с последними строками вывода программы; недописанный результат удаляется,
  в том числе по «Отмене».
- **Размещение.** В круге всегда 8 секторов (клавиши 1–8). Подходящие действия встают в свободные секторы. Если
  не помещаются, последний обычный (не группа) сектор становится группой **Ещё ›**: в её веере сначала вытесненное
  действие, затем ваши (в веере не больше 9, то есть до восьми своих действий на тип файла). Место «Ещё» у типа файла
  всегда одно и то же — привычные клавиши не меняются. Файлы без своего круга (компактный круг) с подходящими
  действиями получают обычный круг: «Сжать в ZIP» и ваши действия (кроме папок и частей файла).
- При нескольких выделенных файлах видны только действия, подходящие **каждому** файлу; действие выполняется
  для каждого.
- Если программы нет на диске, сектор неактивен («Программа не найдена: …»), и список в настройках тоже показывает
  проблему. Команда запускается с вашими правами и может делать всё, что можете вы, — добавляйте только то, чему
  доверяете.
- Действия хранятся в `settings.json` (до 50); испорченные записи при загрузке отбрасываются, не задевая остальные
  настройки.

## Обновления

Проверка обновлений встроена, но **в этом репозитории выключена**: она работает, только если при сборке задан
репозиторий GitHub в свойстве `<UpdateRepository>` файла `src\FileDial.App\FileDial.App.csproj` (`владелец/репозиторий`).
При пустом значении (как сейчас) нет ни пункта в трее, ни настройки, ни сетевых запросов.

Если репозиторий задан:

- Через 30 секунд после запуска, не чаще раза в неделю (время последней проверки — в
  `%APPDATA%\FileDial\update-check.txt`), FileDial спрашивает у GitHub последний выпуск (`releases/latest`; черновики
  и предварительные выпуски не учитываются). Выключается в Настройки → «Проверять обновления раз в неделю». Трей →
  «Проверить обновления» проверяет сразу и сообщает результат в любом случае («У вас последняя версия — 0.2.0.»).
- Новая версия — уведомление «Вышла FileDial X». Клик скачивает ассет `FileDial-Setup-<версия>.exe` (только по https
  с github.com; проверка по размеру и по SHA-256, если GitHub публикует контрольную сумму) в `%TEMP%\FileDial-update-…`
  и запускает его с `--install --quiet --start`: установщик закрывает запущенную копию, заменяет exe, сохраняет
  настройки, автозапуск, ярлыки и пункт контекстного меню и запускает новую версию. Если что-то не так —
  уведомление «Не удалось обновить» открывает страницу выпуска.
- Сетевые ошибки фоновой проверки пишутся только в журнал. Скачанные установщики старше суток удаляются.

## История

Трей → «История…». Каждое действие из круга — запись: что сделано, с каким файлом, когда и чем закончилось
(«Готово», «Ничего не нужно», «Отменено», «Ошибка» — с текстом причины). Записи сгруппированы по дням
(«Сегодня», «Вчера», дата). Кнопки «Показать результат» и «Показать исходник» открывают Проводник с выделенным
файлом; если файл с тех пор удалён или перемещён, кнопки нет, а у результата написано «Результат удалён или
перемещён». Окно обновляется само, пока открыто. «Очистить» срабатывает со второго нажатия (первое спрашивает
«Точно очистить?»).

История хранится только на этом компьютере: `%APPDATA%\FileDial\history.json`, последние 200 записей.
Испорченный файл не мешает работе — история начинается заново.

Настройки хранятся в `%APPDATA%\FileDial\settings.json` (читаемый JSON, кириллица как есть). Файл
записывается атомарно; если он испорчен или в нём странные значения, FileDial берёт значения по умолчанию
или ближайшие допустимые и не падает.

## Сборка для раздачи

```powershell
.\publish.ps1                                     # тесты → публикация → zip и установщик
.\publish.ps1 -SkipTests                          # без тестов
.\publish.ps1 -CertificateThumbprint 0123…4567    # плюс подпись кода
```

Результат:

- `dist\FileDial-Setup-<версия>.exe` (~86 МБ) — установщик, см. «Установка»;
- `dist\FileDial-<версия>-win-x64.zip` (~80 МБ) — переносная версия: exe и оба README, запускается откуда угодно;
- `dist\FileDial\FileDial.exe` — сам exe (.NET и ONNX Runtime внутри, ставить ничего не нужно).

Скрипт печатает SHA-256 архива и установщика.
Версия берётся из `<Version>` в `src\FileDial.App\FileDial.App.csproj`; у exe свой значок и сведения о файле.

- **Сжатый самораспаковывающийся exe** (профиль публикации `src\FileDial.App\Properties\PublishProfiles\win-x64.pubxml`):
  ~86 МБ вместо ~190 МБ без сжатия (столько же качает обновление). При первом запуске exe один раз распаковывается
  в `%TEMP%\.net\FileDial\<хеш>` (~1,5 с); следующие запуски — ~0,2 с, как без сжатия. Память та же (~105 МБ):
  сборки отображаются с диска. При запуске FileDial удаляет распаковки своих прежних версий и распаковки установщиков
  старше часа. Всё, что лежит «рядом с FileDial.exe» (ffmpeg, `models`, README), ищется рядом с настоящим exe, а не
  в папке распаковки.
- **Подпись кода** (необязательно): `-CertificateThumbprint <отпечаток>` (сертификат в `CurrentUser\My`) или
  переменные окружения `FILEDIAL_SIGN_PFX` (путь к `.pfx`) и `FILEDIAL_SIGN_PASSWORD`. exe подписывается `signtool`
  из Windows SDK (SHA-256, метка времени DigiCert) до упаковки, так что и zip, и установщик получают подписанный exe.
  Без этих параметров подпись пропускается.
- ffmpeg и модели в дистрибутив не входят — программа ставит их сама одной кнопкой. Для полностью
  офлайн-дистрибутива положите в `dist\FileDial` `ffmpeg.exe`, `ffprobe.exe`, `models\ggml-base.bin`
  (или `ggml-small.bin`) и `models\isnet-general-use.onnx` и упакуйте заново: `.\publish.ps1 -KeepExtras`.

**GitHub Actions** (`.github/workflows/build.yml`): на каждый push и pull request — тесты на `windows-latest` (тесты,
которым нужен ffmpeg, там пропускаются). Тег `v*` (например, `v0.3.0`; должен совпадать с `<Version>`) — ещё и
`publish.ps1` и выпуск на GitHub с `FileDial-Setup-<версия>.exe` и zip. Подпись в CI включается секретами
репозитория `FILEDIAL_SIGN_PFX_BASE64` (`.pfx` в base64) и `FILEDIAL_SIGN_PASSWORD`.

## Установка

Запустите `FileDial-Setup-<версия>.exe`. Прав администратора не нужно: всё ставится только для вас.

- Слева — тот же круг, что и в программе: при установке он заполняется по часовой стрелке, при удалении гаснет.
- **Папка** — по умолчанию `%LOCALAPPDATA%\Programs\FileDial`, «Изменить…» — любая своя. Если выбрать общую
  папку (`D:\Программы`), программа встанет в `D:\Программы\FileDial`. Установщик сразу проверяет права
  на запись и свободное место: Program Files требует администратора — об этом будет сказано до установки.
- **Оформление** — Графит, Латунь, Бумага или «Как в Windows»; установщик перекрашивается сразу. Здесь же можно
  выбрать язык интерфейса.
- **Дополнительно** — запуск вместе с Windows, ярлык в меню «Пуск», ярлык на рабочем столе, пункт в меню Проводника.
- В конце — как пользоваться (3 шага) и галочка «Запустить FileDial».
- **Обновление** — тот же установщик новой версии: он узнаёт установленную копию, предлагает «Обновить»,
  оставляет папку прежней и не трогает настройки и историю. Запущенный FileDial закрывается штатно
  (идущие задачи отменяются, временные файлы убираются) и после обновления запускается снова по галочке.
- **Удаление** — «Параметры → Приложения → FileDial → Удалить». Удаляются программа, ярлыки, автозапуск, пункт
  контекстного меню и запись в «Приложениях»; из папки — только свои файлы (FileDial.exe, README.md, README.ru.md),
  сама папка — если опустела. По галочке — и настройки, история, скачанный ffmpeg и модели (размер показан).
  Без неё всё сохранится для повторной установки.

Как это устроено: установщик — это тот же `FileDial.exe`. Слово «Setup» в имени файла (или ключ `--install`)
открывает мастер установки, `--uninstall` — удаление (`--dial` всегда означает саму программу). Так в дистрибутиве
нет второй копии .NET.

Для администраторов — без окон:

```powershell
.\FileDial-Setup-0.2.0.exe --install --quiet [--dir "D:\Программы"] [--no-autostart] [--start]
"%LOCALAPPDATA%\Programs\FileDial\FileDial.exe" --uninstall --quiet [--remove-data]
```

Новая тихая установка включает автозапуск, ярлык в «Пуске» и пункт контекстного меню; тихое обновление сохраняет
прежний выбор. `--start` после установки запускает программу (так работает обновление из трея).
Код возврата: 0 — готово, 1 — ошибка (подробности в `%LOCALAPPDATA%\FileDial\errors.log`), 2 — папка не подходит.

Если установщик собран без сертификата (не подписан), Windows SmartScreen при первом запуске может показать
«Неизвестный издатель»: «Подробнее → Выполнить в любом случае».

## Установка ffmpeg

Ставить ffmpeg вручную не нужно: если его нет, FileDial при запуске покажет уведомление у значка в трее
(«FileDial: нужен ffmpeg» — нажмите, чтобы установить), а окно любого действия — кнопку «Установить ffmpeg одной
кнопкой». Обе ведут в Настройки → ffmpeg → «Установить ffmpeg (около 170 МБ)»: прогресс и «Отмена» там же.

- Ставится сборка **gyan.dev «full»** (в ней есть whisper для субтитров): текущая версия берётся из
  `release-version`, контрольная сумма — из файла `.sha256` рядом с архивом. Архив `.7z` распаковывает
  встроенный в Windows `tar.exe` (libarchive) — сторонние программы не нужны.
- Если `tar.exe` нет (старые Windows 10) или gyan.dev недоступен — запасная сборка BtbN с GitHub (`.zip`,
  SHA-256 из GitHub API). В ней нет whisper: всё работает, кроме субтитров и «В текст».
- Архив скачивается во временный файл и проверяется по SHA-256; из него берутся только `ffmpeg.exe` и
  `ffprobe.exe` в `%LOCALAPPDATA%\FileDial\ffmpeg` (без прав администратора). Старые файлы заменяются
  только после успешной проверки и распаковки; временные удаляются.
- Если найденный ffmpeg без whisper, в настройках предлагается «Установить ffmpeg с распознаванием речи»;
  если ffmpeg ставила программа — «Обновить ffmpeg».

Порядок поиска: папка из настроек → рядом с `FileDial.exe` → `%LOCALAPPDATA%\FileDial\ffmpeg` → `PATH`.
Для офлайн-дистрибутива положите `ffmpeg.exe` и `ffprobe.exe` рядом с `FileDial.exe`.

## Как пользоваться

1. Выделите файл поддерживаемого типа (см. таблицу выше) в Проводнике или на рабочем столе.
2. Нажмите **Ctrl+Alt+K** (или правый клик → «Открыть в FileDial…») — круг откроется у курсора.
3. Выберите сектор мышью или клавишами **1–8** (1 — верхний сектор, дальше по часовой стрелке),
   стрелками можно идти по кругу. Клик или **Enter** запускает действие.
   На секторе-группе («Формат», «Переводы строк», «Ещё») снаружи раскрывается веер: наведите мышь на пункт и кликните.
   С клавиатуры: выберите группу цифрой, нажмите **Enter** — откроется веер; дальше **1–N** или стрелки,
   **Enter** — запустить, **Esc** или **Backspace** — назад к основному кругу.
4. **Esc**, клик в центре/вне круга, правый клик или переключение на другое окно закрывают круг
   без каких-либо изменений.

Для других типов файлов (psd, exe…), папок и выделения из файлов разных типов показывается компактный круг
без секторов с подсказкой «Enter или клик — сжать в ZIP». Длинные имена сокращаются в середине, расширение остаётся
видно. В центре круга — имя и размер, а также длительность (видео, звук) или разрешение (картинки), если ffmpeg
найден; у текстовых файлов — число строк и кодировка («12 КБ · 340 строк · UTF-8»), у SVG — размер рисунка
(«4 КБ · 512×512»), у значков — размеры внутри («15 КБ · 7 размеров, до 256×256»).
Неактивный сектор при наведении объясняет, почему он недоступен.
Если активное окно — не Проводник, ничего не выделено или файл недоступен, у курсора появляется
короткое уведомление.

### Анимации

Круг сделан как поворотная ручка: по ободу шкала делений (длинные — напротив секторов), у каждого сектора
значок, название и номер клавиши в углу. При открытии ручка доворачивается на 18° и секторы зажигаются
по часовой стрелке (около 300 мс). Засечка-указатель на ободе переезжает к выбранному сектору коротким путём
и встаёт с лёгкой отдачей, как фиксатор. Выбранный сектор плавно меняет цвет и чуть выдвигается наружу.
Пункты веера разворачиваются из-под сектора-группы один за другим. После выбора сектор уходит
дальше наружу, а круг проворачивается ещё на 8° и гаснет; Esc закрывает так же, но быстрее. Уведомления
проявляются и гаснут, полоса прогресса движется плавно, а для коротких операций без процентов по ней бежит отрезок.
Если в Windows выключены эффекты анимации (Параметры → Специальные возможности → Визуальные эффекты),
всё применяется мгновенно.

### Видео: остальные действия

- «Сделать GIF» — 12 кадров/с, длинная сторона до 480 px, своя палитра. Только для роликов до 30 с
  (длиннее — сектор неактивен с причиной). Имя: `имя.gif`.
- «Извлечь звук» — если звук уже AAC/MP3/Opus/Vorbis/FLAC, копируется без перекодирования (`.m4a`, `.mp3`,
  `.opus`, `.ogg`, `.flac`); иначе кодируется в AAC 192 кбит/с (`.m4a`). Неактивно для видео без звука.
- «Кадр в картинку» — PNG без потерь, кадр на трети длительности (первый кадр часто чёрный). Имя: `имя_кадр.png`.
- «Убрать звук» — видео копируется без перекодирования в тот же контейнер. Имя: `имя_без_звука.ext`.
  Неактивно, если звука нет.
- «Формат ›» — веер MP4 · MKV · WebM · MOV; свой формат файла неактивен («Файл уже в MP4»). Совместимые потоки
  только перепаковываются (секунды, без потерь), иначе перекодируются — см. «Форматы видео». Имя: `имя.mp4` и т. п.

### PDF

Исходный PDF не меняется. Разбор и сборка PDF — библиотека **PDFsharp 6.2.4** (лицензия MIT; версии с 6.5
выходят под AGPL, поэтому версия закреплена). Отрисовка и распознавание страниц — движок PDF самой Windows.

- **Разделить по страницам** — папка `имя (страницы)` с файлами `имя — стр. 01.pdf`, … Для одностраничного
  PDF неактивно. Число страниц показано в центре круга.
- **Извлечь страницы** — окно с записью страниц: `1-3, 5, 8-` (до конца), порядок сохраняется как записан;
  ошибки («В документе 12 страниц», «начало больше конца») видны сразу. Результат — `имя_стр_1-3,5.pdf`.
- **Повернуть вправо / влево** — все страницы на 90°, `имя_повёрнут.pdf`; закладки и свойства сохраняются.
- **Страницы в картинки** — PNG 150 dpi на белом фоне в папке `имя (картинки)`.
- **Распознать текст** — каждая страница распознаётся встроенным OCR Windows (300 dpi) на языке из
  параметров Windows; годится и для сканов. Результат — `имя.txt` (UTF-8), страницы разделены заголовками.
- **Защитить паролем** — пароль дважды, `имя_с_паролем.pdf` с шифрованием AES-256.
- **Объединить** — выделите несколько PDF: один файл в порядке выделения, имя — по папке (`Отчёты_объединено.pdf`).
- PDF под паролем: окно спросит пароль и повторит действие (как у архивов). Копия из защищённого PDF
  собирается из страниц заново и уже без пароля — закладки при этом не переносятся.

### Документы

Исходный документ не меняется. Новые форматы (DOCX, XLSX, PPTX, ODT, ODS, ODP) — это zip с XML: текст,
картинки и сведения об авторе FileDial читает и пишет сам. Остальное делает установленный Office
(невидимо, без макросов, документ открыт только для чтения) или, если Office нет, LibreOffice.

- **В PDF** и **Формат ›** — `имя.pdf`, `имя.odt` и т. п. рядом. DOC → DOCX тоже здесь. В CSV попадает первый лист.
- **В текст** — `имя.txt` (UTF-8): у текста — абзацы, у презентации — по слайдам. Для таблиц — «Формат → CSV».
- **Извлечь картинки** — как лежат внутри, без пересжатия, в папку `имя (картинки)`.
- **Сжать картинки** — фото больше 2000 px уменьшаются, JPEG пересжимается; имена и форматы картинок не
  меняются, документ открывается как прежде: `имя_сжат.docx`. Если выигрыша нет — так и скажет.
- **Убрать личные данные** — `имя_без_данных.docx`: без автора и «кем изменён», компании и руководителя,
  даты печати; у комментариев и исправлений имя заменяется на «Автор», убираются учётные записи
  (почта) и путь к шаблону вида `C:\Users\имя\…`. Текст, комментарии и правки остаются.
- **Защитить паролем** — копия `имя_с_паролем.docx` с паролем на открытие (средствами Office).
- **Собрать в PDF** — выделите несколько документов (можно вперемешку: письмо, таблица, презентация):
  один PDF в порядке выделения.
- Office, который завис (например, ждёт ответа в скрытом окне), через 5 минут завершается; отмена тоже
  завершает только тот процесс Office, который запустил FileDial. Открытый у вас Word или PowerPoint не трогается.

### Текстовые файлы

Исходник не меняется, результаты — новые файлы рядом. Здесь не нужны ни ffmpeg, ни Office, ни Excel.
Действия, которые к файлу не относятся, неактивны с причиной («Только для файлов JSON», «Только для таблиц CSV
и TSV», «Только для файлов Markdown (.md)»); двоичный файл с текстовым расширением получает на всех секторах
«Похоже, это не текст, а двоичный файл».

- **Определение кодировки**: BOM (UTF-8, UTF-16, UTF-32), UTF-16 без BOM, строгая проверка UTF-8, а для однобайтового
  текста — эвристика, выбирающая между Windows-1251, CP866 и Windows-1252. Для круга читаются только первые 4 МБ;
  действия читают файл целиком (до 256 МБ).
- **В UTF-8** — `имя_utf8.txt`, текст перекодируется как есть (переводы строк не меняются). BOM пишется только у
  CSV/TSV — по нему Excel узнаёт кодировку; текст, JSON, XML и скрипты получают UTF-8 без BOM. Неактивно, если файл
  уже в UTF-8 («Уже в кодировке UTF-8») или только из латиницы («Только латиница — это уже годится как UTF-8»).
- **Переводы строк › CRLF · LF** — `имя_crlf.txt` / `имя_lf.txt`. Преобразуются все переводы строк (CRLF, LF,
  одиночный CR); кодировка и BOM остаются прежними (в том числе у UTF-16). Свой стиль файла неактивен («Переводы
  строк уже LF»), у файла из одной строки неактивны оба.
- **В XLSX** (CSV, TSV) — `имя.xlsx`, его пишет сам FileDial. Разделитель (запятая, точка с запятой, табуляция)
  определяется по первым строкам (у `.tsv` по умолчанию — табуляция); кавычки — по RFC 4180, включая переводы строк
  внутри кавычек. Числа становятся числами (кроме значений с ведущими нулями — они остаются текстом), остальное —
  текстом. Итог: «N строк, M столбцов, разделитель — точка с запятой.» Проверяются пределы Excel: 1 048 576 строк,
  16 384 столбца; более длинные ячейки обрезаются до 32 767 символов с пометкой.
- **Форматировать JSON** — `имя_формат.json` с отступами; **Сжать JSON** — `имя.min.json`. Оба пишут UTF-8 без BOM.
  Сломанный JSON (при открытии круга проверяется до 5 МБ) делает оба неактивными с местом ошибки: «Ошибка в JSON:
  строка 3, символ 14»; уже оформленный или уже сжатый файл делает неактивным соответствующий сектор.
- **В HTML** (Markdown) — `имя.html`, самодостаточная страница со встроенными стилями: заголовки, абзацы, вложенные
  списки, цитаты, блоки кода, таблицы GFM, ссылки, картинки, выделение, зачёркивание. Встроенный HTML экранируется —
  страницу безопасно открывать. Если результат сохраняется в другую папку, относительные пути к картинкам
  становятся абсолютными.
- **В PDF** (Markdown) — та же страница, напечатанная в `имя.pdf` Microsoft Edge в фоновом режиме с отдельным
  временным профилем (открытый у вас Edge не затрагивается); таймаут 90 с. Без Edge — «Нужен Microsoft Edge».

### SVG и значки

- **SVG → В PNG** — `имя.png`, длинная сторона 1024 px; вектор рисуется сразу в этом размере, а не растягивается из
  маленькой картинки. **PNG всех размеров** — папка `имя (PNG)` с `имя_16px.png` … `имя_1024px.png` (16, 32, 48, 64,
  128, 256, 512, 1024). **В ICO** — `имя.ico` с кадрами 16, 24, 32, 48, 64, 128 и 256 px (PNG внутри, прозрачные поля
  до квадрата).
- SVG рисует декодер librsvg из ffmpeg. Если в используемом ffmpeg его нет, все три сектора неактивны с причиной
  «В вашем ffmpeg нет декодера SVG (librsvg)». Учтите, что он есть не у каждой «full»-сборки —
  см. «Ограничения».
- **ICO → В PNG** — `имя.png` самого крупного размера; **Все размеры в PNG** — папка `имя (PNG)` с файлом на каждый
  размер (`имя_32x32.png`, …). Оба работают без ffmpeg (кадры PNG и BMP: 32-битные с прозрачностью и с палитрой
  и маской). «Все размеры в PNG» неактивно для значка с одним размером («В значке только один размер»).
- **Картинка → Формат › ICO** — `имя.ico` со стандартными размерами до собственного размера картинки (маленькие
  картинки не растягиваются больше чем до 48 px).

### Архивы

Сторонние программы не нужны: zip читает и пишет .NET, остальные форматы — встроенный в Windows `tar.exe`
(libarchive; есть с Windows 10 1803). Исходный архив не меняется и не удаляется.

- **Распаковать сюда** — «умно»: если в архиве одна общая папка (или один файл), она появляется прямо рядом
  с архивом, без «Архив\Архив\…»; иначе — папка с именем архива. **Распаковать в папку** — всегда в папку с
  именем архива. **Распаковать в…** — в выбранную папку. Существующее не перезаписывается (`имя_2`).
- Распаковка идёт во временную папку `.filedial-…`: при ошибке, пароле или отмене ничего «наполовину
  распакованного» не остаётся. Записи вида `../` за пределы папки отклоняются.
- zip, созданные старым Проводником (имена в cp866 без флага UTF-8), распаковываются с правильными русскими именами.
- **Проверить архив** — читает всё содержимое и сверяет контрольные суммы, на диск ничего не пишет.
- **Формат › ZIP / 7z** — перепаковка (например, rar → zip для тех, у кого нет архиватора). 7z сжимает лучше zip.
- **Сжать в ZIP** — для файлов без своего круга, папок и выделения из файлов разных типов: в компактном круге Enter
  или клик. Одна папка или файл → `имя.zip`, несколько → по имени их папки. Имена в UTF-8, пустые папки сохраняются.
- **Содержимое** — окно со списком без распаковки: дерево папок (как в Проводнике: папки, потом файлы),
  размеры, итог «N файлов · X МБ после распаковки» и кнопка «Распаковать сюда». Список виртуализирован —
  архив на десятки тысяч файлов открывается без задержек.
- В центре круга архива — размер и число файлов.
- **Защитить паролем** — пароль вводится дважды (не короче 6 символов), рядом появляется `имя_пароль.zip`
  с шифрованием **AES-256** (формат WinZip AE-2: открывают 7-Zip, WinRAR, Проводник Windows 11). .NET такие
  архивы писать не умеет, поэтому формат реализован в FileDial по спецификации (PBKDF2-HMAC-SHA1, AES-CTR,
  код подлинности HMAC) и проверяется тестами независимым читателем — libarchive. Имена файлов в ZIP видны
  без пароля — так устроен формат. Файлы больше 4 ГБ в архив с паролем пока не помещаются.
- **Разбить на части** — размер части на выбор: 10 МБ, 25 МБ (почта, мессенджеры), 100 МБ, 700 МБ, 1 ГБ,
  4 ГБ (флешки FAT32); окно сразу показывает число частей, размеры не меньше файла неактивны. Рядом
  появляются `имя.zip.001`, `.002`, … — простое деление по байтам, которое понимают 7-Zip и WinRAR
  (открывают .001 и собирают сами). Части пишутся во временные файлы и получают имена только в конце —
  при ошибке или отмене «половины набора» не остаётся; занятые имена не перезаписываются (`имя_2.zip.001`).
- **Собрать из частей** — выделите любую часть (или все сразу): компактный круг покажет «имя · N частей ·
  размер», Enter — собрать. FileDial проверит, что части идут подряд и одного размера (последняя не больше),
  и соберёт файл рядом; если исходный ещё лежит там же — `имя_2.zip`. Части не удаляются.
- **Архивы с паролем** (ZIP: ZipCrypto и AES): при распаковке, проверке и перепаковке окно спросит пароль,
  при ошибке — «Неверный пароль» и ещё попытку; ничего «наполовину распакованного» не остаётся. Зашифрованные
  7z и RAR встроенный `tar.exe` не открывает — FileDial так и скажет. Пароль нигде не сохраняется; он
  передаётся `tar.exe` аргументом (ограничение утилиты) и потому должен быть в ANSI-кодировке.
- Ограничение `tar.exe` Windows: пути он получает в ANSI-кодировке системы (cp1251 для русской Windows).
  Имена **внутри** архива и папки назначения могут быть любыми (`Ünïcödé`, `日本`) — FileDial передаёт папку
  как рабочий каталог, а путь к архиву с такими символами — коротким именем 8.3. Если на диске короткие
  имена выключены, будет понятная ошибка. 7z из файла или папки, в **имени** которых есть такие символы,
  не создаётся — FileDial предложит ZIP (его пишет .NET, ограничений нет).

### Обрезать

После выбора «Обрезать» открывается окно с длительностью файла и полями «Начало» и «Конец». Время вводится
как `83`, `83,5`, `1:23`, `1:23.5` или `1:02:03`; ошибки и длина отрезка видны сразу, кнопка «Обрезать»
активна только для правильного отрезка. Для видео — флажок «Точно по кадрам»: включён — видео
перекодируется (H.264/AAC, для WebM — VP9/Opus) и режется точно; выключен — копируется без перекодирования
за секунды, но границы сдвигаются к ближайшим ключевым кадрам. Звук всегда режется точно.
Имя: `имя_обрезка.ext`.

### Форматы видео

- MP4: H.264 + AAC копируются, иначе H.264 CRF 20 + AAC 192 кбит/с.
- MOV: H.264/HEVC + AAC копируются, иначе H.264 + AAC.
- WebM: VP8/VP9/AV1 + Opus/Vorbis копируются, иначе VP9 (CRF 32) + Opus 128 кбит/с — заметно медленнее.
- MKV: всегда копирование без потерь (MKV принимает почти любые кодеки).

### Изображения

- Результат — новый файл рядом с исходником; исходник не меняется, метаданные (EXIF) в результат не переносятся.
- Форматы: JPG, PNG, WebP, BMP, TIFF (LZW), GIF (своя палитра), ICO (см. «SVG и значки»). «Повернуть влево» —
  `имя_повернуто_влево`, «Отразить» — по горизонтали, `имя_отражено`.
- «В JPG» и «В BMP»: прозрачные места заливаются белым (в JPG нет прозрачности), качество `-q:v 2`, 4:4:4.
- «В WebP»: качество 90, прозрачность сохраняется. «В PNG» — без потерь.
- «Уменьшить до 1920 px»: длинная сторона 1920, пропорции сохраняются (lanczos). Неактивно, если картинка
  уже не больше 1920 px. Имя: `имя_1920px.ext`.
- «Повернуть вправо»: на 90° по часовой. Имя: `имя_повернуто.ext`.
- Поворот и уменьшение сохраняют формат JPG/PNG/WebP; BMP, GIF и TIFF сохраняются как PNG.
- У анимированных GIF/WebP берётся первый кадр.
- «Сжать до 1 МБ» — JPG с наилучшим качеством, которое помещается в 1 000 000 байт (двоичный поиск по
  шкале качества). Если не помещается даже худшее качество, картинка уменьшается шагами по 25%.
  Неактивно для файлов меньше 1 МБ. Имя: `имя_1мб.jpg`.
- «Убрать фон» — см. «Убрать фон».
- Смена формата сохраняет имя (`фото.png` → `фото.jpg`); если имя занято — `фото_2.jpg`.
  Конвертация в свой же формат неактивна («Файл уже в PNG»).

### Звук

- «В MP3» — LAME VBR ~190 кбит/с; «В M4A» — AAC 192 кбит/с; «В WAV» — PCM 16 бит.
- «Выровнять громкость» — EBU R128 (`loudnorm`, −16 LUFS), формат и частота дискретизации исходника
  сохраняются. Имя: `имя_выровнено.ext`.
- «Убрать шум» — шумоподавление `afftdn`. Имя: `имя_без_шума.ext`.
- «Ускорить ×1,5» и «Замедлить ×0,75» — без изменения высоты голоса (`atempo`). Имена: `имя_x1,5.ext`,
  `имя_x0,75.ext`.
- «В моно» — сведение каналов в один, `имя_моно.ext`. Неактивно, если звук уже моно.
- Форматы: MP3, M4A (AAC), WAV, FLAC, OGG (Vorbis), Opus.
- Берётся первая звуковая дорожка, обложка не переносится. Прогресс — в процентах по длительности.

### Сжатие до 25 МБ

- Цель — 25 000 000 байт. Длительность берётся из `ffprobe`.
- Двухпроходное кодирование H.264 (`libx264`, preset medium) + AAC 128 кбит/с.
  Общий битрейт = 25 000 000 × 8 × 0,97 / длительность (запас 3%), видео = общий − 128.
- Если на видео остаётся меньше 300 кбит/с, длинная сторона кадра уменьшается до 854 / 640 / 426 пикселей
  (в зависимости от битрейта).
- Сектор «Сжать до 25 МБ» не предлагается, если сжатие не нужно или невозможно. Причина видна в центре круга:
  - файл уже не больше 25 МБ — «Файл уже меньше 25 МБ»;
  - на изображение осталось бы меньше 50 кбит/с — «Видео длиннее 18 мин в 25 МБ не уместить»
    (без звука предел около 64 минут);
  - в файле нет видеодорожки.

  Длительность проверяется через ffprobe при открытии круга (~50 мс, таймаут 2 с). Если ffmpeg не найден
  или ffprobe не ответил, сектор остаётся активным, а окно сжатия объяснит проблему.
- Перед кодированием проверяется, что в папку с исходником можно писать и на диске есть хотя бы 30 МБ
  (результат + 20%). Иначе сразу понятная ошибка, а не падение после нескольких минут работы.
- Многоканальный звук (5.1, 7.1) сводится в стерео: 128 кбит/с на шесть каналов звучат плохо.
- Повторный запуск сжатия того же файла, пока идёт первое, не начинает второе кодирование,
  а показывает уже открытое окно.
- Если после второго прохода файл всё же вышел больше цели, второй проход один раз повторяется
  с битрейтом, уменьшенным на величину перебора («Проход 2 из 2, уточнение»).
- Результат: `имя_25мб.mp4` рядом с исходником; если имя занято — `имя_25мб_2.mp4`, `имя_25мб_3.mp4`…
  Существующие файлы не перезаписываются. Исходный файл только читается.
- Временные файлы (`.filedial-*.tmp` рядом с исходником и журналы проходов в `%TEMP%\FileDial`)
  удаляются и при успехе, и при ошибке, и при отмене.
- Окно прогресса показывает этап и проценты (из `ffmpeg -progress`), есть кнопка «Отмена».
  По завершении — итоговый размер и кнопка «Показать в папке».

## Ограничения

- **Окна с правами администратора.** FileDial работает без прав администратора. Если окно Проводника
  запущено с повышенными правами, Windows (UIPI и уровни целостности) не даёт обычному процессу читать
  из него выделение. FileDial распознаёт такую ситуацию и показывает уведомление «Окно запущено с правами
  администратора — выделение недоступно». Запускать FileDial от администратора ради этого не нужно и не
  рекомендуется.
- Фокус: круг забирает фокус клавиатуры сразу после открытия (Windows разрешает это процессу, получившему
  горячую клавишу). Если система всё же не отдала фокус, круг закрывается через ~0,4 с, чтобы не
  остаться висеть поверх окон.
- Выделение читается только из обычных окон Проводника (`CabinetWClass`) и рабочего стола.
  Диалоги «Открыть/Сохранить» других программ не поддерживаются.
- Виртуальные элементы (например, внутри zip-архива, «Этот компьютер», корзина) считаются недоступными.
- **Контекстное меню Windows 11.** «Открыть в FileDial…» есть только в классическом меню («Показать дополнительные
  параметры»), а не в новом компактном.
- Документы под паролем (DOCX и т. п.) FileDial не открывает: Office получает заведомо неверный пароль, чтобы
  не повиснуть со скрытым запросом, и FileDial сообщает «документ защищён паролем».
- «Убрать личные данные» и «Извлечь картинки» — только для новых форматов (DOCX, XLSX, PPTX, OpenDocument).
- **SVG нужен ffmpeg с librsvg.** Он есть не в каждой сборке: в проверенной на машине разработки сборке gyan.dev
  «full» 9.0.1 декодера SVG нет, поэтому секторы SVG там неактивны. Нужен ffmpeg, у которого в `ffmpeg -decoders` есть `librsvg`; укажите его в Настройки → ffmpeg.
- **Кодировка определяется эвристикой.** Файлы с BOM, UTF-16 и UTF-8 распознаются надёжно; для однобайтового текста
  FileDial различает только Windows-1251, CP866 и Windows-1252, и короткий или необычный текст может быть угадан
  неверно. Другие кодировки (KOI8-R, Windows-1250…) не распознаются.
- **«Убрать фон»** — нейросеть общего назначения: на необычных картинках (несколько объектов, фон в тон объекту,
  стекло, волосы, рисунки) маска может быть грубой или убрать лишнее. Исходник при этом не меняется.
- Markdown → HTML поддерживает распространённое подмножество Markdown (без сносок и формул); встроенный HTML
  показывается как текст.
- Непредвиденные ошибки пишутся в `%LOCALAPPDATA%\FileDial\errors.log` и не роняют программу.

Получение выделения (без эмуляции Ctrl+C и без буфера обмена):

- `GetForegroundWindow` → класс окна.
- **Проводник** (`CabinetWClass`): `Shell.Application.Windows()`, отбор по `HWND`. В Windows 11 у всех
  вкладок одного окна общий `HWND`, поэтому для каждого кандидата через
  `IServiceProvider::QueryService(SID_STopLevelBrowser) → IShellBrowser::GetWindow` берётся окно вкладки
  и сравнивается с видимым дочерним `ShellTabWindowClass` — это активная вкладка. Если активную вкладку
  определить не удалось, выделение не читается (ошибка, а не данные из чужой вкладки).
  Затем `Document.SelectedItems()`.
- **Рабочий стол** (`Progman` или `WorkerW` с `SHELLDLL_DefView`): `IShellWindows::FindWindowSW(SWC_DESKTOP)` →
  `IShellBrowser::QueryActiveShellView` → `IShellView::GetItemObject(SVGIO_BACKGROUND)` → `SelectedItems()`.
- Все COM-вызовы — в отдельном STA-потоке с таймаутом 5 с; COM-объекты освобождаются, исключения
  перехватываются.
- Пункт контекстного меню идёт тем же путём: `FileDial.exe --dial` подаёт сигнал запущенной копии (именованное
  событие), и она читает выделение активного окна Проводника, как после горячей клавиши.
- ffmpeg/ffprobe и свои действия запускаются через `ProcessStartInfo.ArgumentList` — каждый аргумент отдельно,
  поэтому пути с пробелами и кириллицей передаются без ручного экранирования и без командной оболочки.
